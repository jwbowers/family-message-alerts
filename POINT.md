# Point

Jake reads this work, and so does any later session that helps him with
it. After reading it, Jake should be able to set up Cara's iPhone, Apple
Watch, and Mac so that a message from a family member produces a signal
that she notices while she is working, that repeats until she
acknowledges it, and that makes no sound. The work is meant to make Cara
stop missing family messages during work.

The work does not claim that the Watch can play one long continuous
buzz, because Apple gives third-party code no way to do that. It does
not claim that any app can read Cara's messages, because Apple lets no
third-party app read them. And it does not claim that a plan works until
Cara has tried it on an ordinary working day.
